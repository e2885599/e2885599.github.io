總覽：概念依賴全鏈

影片的核心手法是嚴格依賴序：後項概念若依賴前項未定義詞，理解鏈斷裂。下圖為全鏈 DAG（葉節點為聽眾已知錨）。

底本 00:00 ~ 21:19 嚴格拓撲序；任何前向引用（如先講 Transformer 再補 Token）都會斷鏈。

一、神經網路：模式學習機

神經網路是由多層微小數學單元（神經元）組成的機器學習模型，鬆散受腦啟發，但不是數位大腦——它是一台模式學習機（底本 00:44 ~ 00:59）。

單一神經元的數學驚人地簡單：

\[ y = \phi\!\left(\sum_i w_i x_i + b\right) \]

其中 \(w_i\) 為權重（像音量旋鈕控制哪些訊號重要），\(b\) 為偏置（平移神經元的觸發門檻），\(\phi\) 為活化函數（決定結果向前傳遞的強度）。單一神經元幾乎無用，但堆疊數千到數百萬個跨多層，就湧現辨識能力（底本 01:33 ~ 01:54）。

影像網路：早期層偵測邊緣，中層組合成形狀，深層認出眼睛/耳朵/鬍鬚，最終層合成「貓」的概念（底本 01:49 ~ 02:09）。
可證偽聲稱 A：網路從近乎隨機權重開始，從資料中學出有用權重；這些權重集體編碼模型發現的模式（底本 02:09 ~ 02:18）。

二、訓練與推論：兩種模式

空網路是「空機器」，須經訓練發現正確權重，再用推論回答（底本 02:27 ~ 03:04）。學生類比：讀書做題＝訓練；考試作答＝推論（底本 03:06 ~ 03:11）。

  • 訓練：展示數百萬例，模型預測；錯則懲罰，權重更新，略好一點；重複數十億次→真正「懂」（底本 03:28 ~ 03:46）。
  • 推論：學完後部署到伺服器，使用者打 API，模型瞬間回答，不再更新權重，只用既有知識預測下一個 token（底本 03:48 ~ 04:06）。
關鍵分界

訓練一次，推論服務數百萬使用者。訓練是模型「學習」，推論是模型「回答」（底本 04:08 ~ 04:15）。混淆兩者會誤判成本結構。

可證偽條件：若「推論階段模型權重仍持續更新」為真，則每次 API 呼叫後同一 prompt 行為應漂移；實測固定 prompt 行為穩定→反證推論不更新權重。

三、Token：語言的原子

當你輸入「Write a story about a robot exploring Mars」，模型不是接收整句，而是分詞器先切成 token（底本 05:09 ~ 05:19）。Token 不總是完整單字：

\[ \text{unbelievable} \;\to\; \text{un}\;|\;\text{believe}\;|\;\text{able} \]

常見字如 the 保持完整，罕見術語可能被切成多個 token；空格、標點、emoji 片段也可成 token（底本 05:24 ~ 05:50）。切分理由是可控詞彙表：模型無法預存人類可能發明的每個詞，改學可複用小片段（如後綴 ing 可跨千詞複用，底本 06:04 ~ 06:18）。

可證偽聲稱 B：分詞後每個 token 獲得數值 ID（如 cat=8241、kitten=17903），這些只是「條碼標籤」而非定義；模型對數值表示做數學以預測下一 token（底本 06:29 ~ 06:49）。

四、Embedding：從 ID 到意義

Token 只是標籤——cat=8241 並未告訴模型「貓與幼貓相關」。意義來自 Embedding（底本 06:55 ~ 07:04）。

訓練中模型調整向量，相似語境的 token 漸獲相近位置；意義＝座標距離（底本 07:40 ~ 07:54）。
可證偽聲稱 C：向量算術具示意性——king − man + woman ≈ queen；Paris − France + Italy ≈ Rome（底本 08:12 ~ 08:21）。影片明確標註「這是有用示意，非完美定律」（底本 08:18）。
證據強度：★★☆ 經典詞嵌入確實呈現此結構，但現代上下文化嵌入（見下節）使固定向量算術不穩定；影片已標邊界，屬誠實外推。

五、Attention：上下文感知

傳統 embedding 給每個詞固定座標，但「bank」在「錢」與「河岸」語意不同。缺失的成分是上下文（底本 09:07 ~ 09:18）。

Self-attention 讓模型比較 mouse 與其他 token，問「哪些詞對解讀它有用以」：在「開檔案、我點擊 mouse」中，open/file/clicked 得高分；在「飢餓的貓追逐 mouse」中，cat/chased 得高分（底本 09:52 ~ 10:39）。

多個 attention head 可同時捕捉不同關係（如名詞指代、動作指向，底本 10:45 ~ 10:57）。
歷史校正（可證偽聲稱 D）：Attention 不是 2017 發明，早已存在數年；2017 Google 論文《Attention Is All You Need》的突破是「把 self-attention 置於模型中心」提出 Transformer（底本 11:04 ~ 11:18）。

六、Transformer：重複架構

LLM 與 Transformer 不是同一物：LLM 是訓練來處理/產生語言的模型；Transformer 是建造它的架構（藍圖）——像成品車 vs 引擎設計（底本 12:04 ~ 12:28）。

運作：prompt 分 token → 每 token 成 embedding 向量 → 加位置資訊（否則「狗咬人」與「人咬狗」同組件，底本 12:33 ~ 12:43）→ 進入堆疊的 Transformer 塊。每塊兩階段：

  • Self-attention：每 token 測量與早前 token 的相關性，連接代詞與名詞、消解歧義（底本 12:51 ~ 13:03）。
  • Feed-forward：在每位置處理資訊，產生更豐富表示；殘差連接保留早前資訊、層歸一化維穩（底本 13:05 ~ 13:25）。
最後層對每個可能下一 token 打分，選一個加入序列，如此反覆生成完整回應（底本 13:48 ~ 14:03）。

七、上下文視窗與 O(n²) 成本

Attention 有邊界：標準 self-attention 中每 token 與允許範圍內每個 token 比較。10 個 token ≈ 100 次比較；1000 個 ≈ 100 萬次；長度翻倍，注意力成本約增 4 倍（底本 14:35 ~ 14:59）。

\[ \text{比較數} \approx n^2 \quad\Rightarrow\quad \text{成本} \propto \mathcal{O}(n^2) \]

這就是上下文視窗：模型的「工作書桌」。prompt、對話史、參考資料、自身回應都須佔用桌面空間；桌面滿了就必須壓縮、丟棄舊 token（底本 15:08 ~ 15:33）。

更大上下文視窗不保證完美召回：重要細節仍可能埋在數千頁中；處理無用 token 也耗時費錢（底本 15:33 ~ 15:47）。這是 RAG 的動機（底本 16:07 ~ 16:18）。
可證偽聲稱 E：標準 self-attention 的計算/記憶成本隨序列長度平方成長，是每個模型都有上下文視窗邊界的根因（底本 14:53 ~ 15:08）。

八、縮放定律

當以不同參數量、資料量、算力訓練 Transformer，其改善呈驚人平滑模式：三者在正確比例下放大，錯誤率可預測下降（底本 16:54 ~ 17:09）。這就是神經縮放定律，關鍵在「可預測」——用小型模型測試即可估算大型模型表現，免耗數百萬訓練（底本 17:13 ~ 17:21）。

尺度與成本同體

縮放帶來能力也帶來成本。資料品質、架構、優化仍重要；過大但資料不足的模型浪費算力，且邊際收益遞減（底本 17:23 ~ 17:41）。

可證偽條件：若「參數量單獨決定智力」為真，則純堆參數應持續線性提升；實測資料/架構不匹配時增益飽和→反證單維假說（底本 20:35 ~ 20:44）。

九、預訓練與後訓練

現代 LLM 通常兩階段建造（底本 18:10 ~ 18:16）：

階段任務學習信號
預訓練隨機權重開始，在巨量文本/程式碼（可能數兆 token）上訓練，主任務＝預測下一 token自監督：文本自身即標籤（底本 18:20 ~ 18:47）
後訓練學會遵循指令、對話、產生更安全有用的回應監督微調 / 偏好優化 / RLHF（底本 19:15 ~ 19:25）
可證偽聲稱 F：基礎模型（base model）本身已是 LLM，但優化目標是「續寫文本」而非「遵循指令」；後訓練把它打磨成你實際互動的助理（底本 19:34 ~ 19:36）。

十、LLM 與產品分界

LLM 是在巨量文本/程式碼上訓練、學習語言模式的神經網路，多數生成式 LLM 用 Transformer 架構、以預測下一 token 為目標（底本 19:50 ~ 20:09）。

\[ \text{參數} = \text{訓練中調整的學習數值} \quad (\text{GPT-3}: 175\times10^9) \]
產品 ≠ 模型

LLM 是模型；ChatGPT / Claude / Gemini 是「由語言模型驅動的助理產品」，通常結合工具、安全系統、使用者介面（底本 20:46 ~ 21:02）。混淆兩者會誤判責任邊界。

可證偽條件：若「參數量＝智力」為真，則 GPT-3（175B）應全面優於後訓練更小的模型；實測後訓練與資料品質主導實用表現→反證單維假說（底本 20:33 ~ 20:44）。

十二、反向提問

不可壓縮、可證偽反向提問：若將本筆記的「概念依賴全鏈」打散為獨立條目（取消拓撲序），能否用試映實驗證明聽眾對「Token/Embedding/Attention」的正確遞進理解率不下降？若下降，則「依賴序不可縮編」即為真——請給可測量驗收實驗（如前測/後測錯誤率差異顯著性檢定）。
