# 高維度空間 · 互動字幕與配音頁 — 使用說明

## 為什麼不能直接雙擊開？
本頁有英語 TTS 配音（13 章／約 18:32）。Chrome 瀏覽器對 `file://`（雙擊直接開）有安全限制，
會**靜默擋掉音訊與互動**——表現為：播放鈕按了沒反應、上下章點了不切換、聲音播不出。
這不是壞檔，是瀏覽器限制。

## 正確開法（擇一）

### 方法 A：本機伺服器（最簡單，免上傳）
1. 開「檔案總管」進到本目錄（`higher-dimensions` 資料夾）。
2. 在資料夾上方的**網址列**點一下，輸入 `cmd` 按 Enter（會開黑色命令視窗）。
3. 黑窗裡輸入並按 Enter：
   ```
   python -m http.server 8765
   ```
4. 看到 `Serving HTTP on port 8765` 就成功了。**這個黑窗保持開著不要關。**
5. 打開 Chrome，網址列輸入：
   ```
   http://localhost:8765/
   ```
6. 點「▶ 播放配音」→ 聲音完整播出，章節導覽同步高亮。

### 方法 B：GitHub Pages 線上（推上去後）
網址 `https://e2885599.github.io/higher-dimensions/` 直接是 https 環境，開了就能播，
不必開本機伺服器。需由工作室推送後才生效。

## 檔案結構
- `index.html` — 頁面
- `app.js` — 互動邏輯（章節導覽、真音訊播放、字幕同步）
- `subtitles.js` — 13 章中英雙語字幕
- `audio_manifest.js` / `audio_manifest.json` — 每章音訊路徑與時間邊界
- `audio/ch00.mp3 … ch12.mp3` — TTS 英語配音（聲線 en-NZ-MollyNeural，48 kbps）
- `raw.srt` / `cues.json` — 原始轉錄稿與解析

## 聲音相關說明
- 配音為 edge-tts 免費合成，固定 48 kbps（語音位元率），18:32 約 6.4 MB 屬正常。
- 若想更高音質需換付費 TTS（edge-tts 不支援調位元率）。
- 拖曳進度條跨章跳躍：在真實瀏覽器（http 環境）中可正常拖動。

## 疑難排解
- **仍播不出**：確認網址是 `http://localhost:...` 而非 `file:///...`（看網址列開頭）。
- **頁面全沒反應**：按 `Ctrl+F5` 硬重新整理，清除舊快取。
- **黑窗關掉後頁面連不上**：重新執行步驟 3 的指令。
